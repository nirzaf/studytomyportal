# Plans and Feature Availability

This repository is used for local development and does not document a deployed Studytomy service, public pricing, subscription tiers, or hosted usage limits. Do not use plan values shown in development data as a promise of a live service.

## Self-hosted editions

The open-source Community Edition is limited to the capabilities included in this repository. Some features described elsewhere in these docs require a separately licensed Enterprise Edition. See [Enterprise Edition](/enterprise) for the licensing boundary and the relevant configuration names.

Feature availability can also depend on the installed edition and local configuration. An unavailable feature should not be treated as available merely because its menu item, model, or route exists in the source tree.

## Organization usage

The dashboard may show organization usage and feature availability when those capabilities are enabled by the installed edition. This local repository does not establish hosted plan limits, upgrade links, payment terms, or service availability.

For the feature and navigation settings available in the organization dashboard, see [Organization Settings](/platform/organizations/settings).
