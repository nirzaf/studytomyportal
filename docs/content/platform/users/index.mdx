# Users and Access

Every person in Studytomy Portal has one account and can belong to several organizations. Inside each organization they hold one role, which decides what they can see and do there.
You manage people from **Users** in the dashboard sidebar. The page has these tabs:

| Tab | What you do there |
| --- | --- |
| **Users** | Search, filter and export members, change roles, remove people, open learner analytics |
| **UserGroups** | Group members and give the group access to courses and other content |
| **Roles** | Review default roles and, when enabled, create custom roles with their own permissions |
| **Signups & Invite Codes** | Choose open or invite-only signup, create invite codes, add custom signup fields |
| **Invite Members** | Invite people by email |
| **Sign-in** | Choose which sign-in methods members may use |
| **Two-factor** | Require two-factor authentication for members |
| **Audit Logs** | See who did what in the organization (Enterprise Edition) |

Self-hosted instances have no plan limits. Audit logs need the [Enterprise Edition](/enterprise).

## Feature availability

Available controls depend on the installed edition and server configuration. This repository does not document hosted subscription tiers or member limits. See [Plans and Feature Availability](/platform/organizations/plans) for the scope of those docs.
