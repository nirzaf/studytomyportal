# Local Development and Self-hosting

This repository is currently used for local development. It does not document a deployed Studytomy hosting service or make service-level claims about support, uptime, backups, or pricing.

## Run the code locally

Use the [quickstart](/getting-started/quickstart) and [CLI dev mode](/cli/dev-mode) guides to start the application from this source checkout.

## Self-hosting references

The repository includes CLI setup, database, storage, and reverse-proxy code. Review the [self-hosting guide](/self-hosting), [system requirements](/self-hosting/installation/requirements), and [maintenance documentation](/self-hosting/maintenance) before using those paths. The presence of setup code does not establish a supported Studytomy release or deployment.
