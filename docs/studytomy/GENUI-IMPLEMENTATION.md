**Reading order:** chronological evidence ledger, not a current feature matrix. Initial missing routes/practice statements describe that checkpoint; inspect current routes and services. Practice remains policy-gated, and intercepted browser responses are not end-to-end backend acceptance.

Scored visuals follow the server-issued item, and exploration stays interactive. Learning surface records remain separate from grades and mastery. ## GENUI-02 — Local contract checkpoint

`apps/api/src/services/ai/schemas/learning_surface.py` defines the version 1 surface and action request schemas. `apps/web/services/ai/learningSurface.ts` validates received values at runtime. The model-facing schema accepts only a visual selector. The learner payload contains a bounded set of plain-text and native visual components, an activity content identity, and surface, turn, request, and revision identifiers. The action payload contains a bounded answer or a named operation, with a request identifier and expected revision. Neither wire shape grants authority or accepts an answer key.

- API contract tests: 16 passed. Targeted Ruff passed.
- Web contract tests: 2 passed with 14 assertions. Targeted strict ESLint and a strict TypeScript check of the validator passed. Both validators use the same synthetic fractions fixture.
- No route, durable attempt store, provider invocation, or learner-facing UI is connected at this checkpoint. The next integration step is the authorized source binding and ungraded practice state described in GENUI-03. There is no migration or feature activation in this contract slice.

## GENUI-05 — Versioned generation stream

The lesson AI router now offers an explicit version 1 generation stream and a no-store recovery read. The generation service checks the current reader and approved lesson visuals before reserving a credit, gives the existing provider only the visual allowlist and learning mode, and constructs the public surface and private evaluation basis from fixed templates. A second source and policy check runs before the transaction commits. Recovery and repeated generation requests return the committed surface without another provider call. The legacy text stream and its follow-up ordering are unchanged.

The browser transport checks the media type, bounds the response, assembles fragmented UTF-8, and validates the single complete event against the requested activity, mode, request ID, and revision. ## GENUI-06 — Ungraded answer and hint actions

The lesson AI router now accepts version-checked practice actions. The service parses bounded integer or fraction input and compares exact rational values with the private evaluator basis. A PostgreSQL row lock serializes actions on the same surface. A committed hint advances the revision before disclosure, so an answer racing with it needs the new revision and records that assistance. A repeated request with the same content returns the saved projection. Reusing its ID with different content returns a conflict. Recovery returns the latest committed revision, while generation replay preserves the initial response.

Correct and incorrect results offer a deterministic next question or retry within the same approved visual. Each new question gets a fresh identity and evaluation basis. No provider or formal assessment is involved in these actions. Migration `61b26e413fa2` adds the action ledger, gives each request and revision a unique key, and prevents in-place changes to saved evidence on both supported test dialects. Controlled retention of that evidence still requires policy approval, and a rollback should preserve the records.

The additive migration rehearsal on disposable loopback PostgreSQL 16 reached `61b26e413fa2` from `f5a8b3d0c2e4`. Seven PostgreSQL-marked tests passed (170 deselected). A separate empty database bootstrapped at the same head and both focused practice tests passed. The tests covered concurrent duplicate answers, a hint and answer race, recovery, mismatched retries, and database rejection of in-place evidence updates. The container was removed. Focused API regressions passed 92 tests, and seven web tests passed with 39 assertions. Targeted Ruff and ESLint passed.
