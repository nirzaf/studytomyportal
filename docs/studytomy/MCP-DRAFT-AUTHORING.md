# Studytomy MCP draft authoring

For local testing, set `LEARNHOUSE_STUDYTOMY_MCP_DRAFTS_ENABLED=true` before starting the FastAPI app. The default omits these tools. The existing `LEARNHOUSE_MCP_ENABLED` server control and organization MCP setting must also allow the connection. Use the existing authenticated streamable HTTP endpoint at `/mcp` with a member OAuth connection issued for that endpoint and organization. Use the existing OAuth write grant (`mcp:write` with `mcp:read`) and a member role with native course-create permission. Keep testing on loopback with synthetic data. The setting adds two tools to the existing registry and leaves that registry's other tools subject to their existing controls.

1. Call `studytomy_create_draft_course` with `{"request_id":"dceea250-1ada-4e20-9b73-f0c9c61901bc","title":"Fractions practice"}`. Complete the MCP human approval prompt or approval link. The result contains the course UUID and the starter Lessons chapter UUID.
2. Call `studytomy_create_draft_lesson` with a new UUID in `request_id`, the returned values in `course_uuid` and `chapter_uuid`, a `title`, and optional plain `text`. Approve this write separately. The result also contains the native activity UUID.
3. For an uncertain response, repeat the same input with the same request ID. The ledger scopes receipts to the organization, actor, and operation and retains them for 30 days. A changed payload with the same key conflicts during that period. Current permissions still apply.

The lesson tool requires active creator ownership of a private, unpublished Studytomy-managed course in the authenticated organization and a chapter linked to that course. API-token connections and read-only connections cannot use either tool. Lesson text is capped at 12,000 characters and 100 lines. Markup and URLs are stored as literal text. There are no imports, embeds, attachments, rich text, assessments, publication actions, or permission changes in these tools. The course enters the existing Studytomy review and publication process. Per-call MCP approval authorizes a draft write only.

The database transaction records resource IDs, actor, organization, and event type alongside the draft and retry receipt. The draft title and lesson text are omitted from the MCP audit payload. Use synthetic content in local testing and keep the feature disabled for real-user use pending applicable approval and acceptance.
