# Demo bundle provenance

Everything in this bundle is original work produced for LearnHouse and is
redistributable under the repository's licence, with one qualified exception:
the ten spoken episode clips under `media/podcasts/` are synthesized with a
voice supplied by the operating system (see *Audio* below). Nothing here
depicts a real person or organisation.

## Imagery

All images under `media/` are generated by
`apps/api/scripts/build_demo_media.py`. They are flat vector compositions drawn
with Pillow from a fixed palette defined in that script. Re-running it
reproduces the same bytes for the images; it does **not** reproduce the podcast
audio on a host without macOS `say` and `ffmpeg` (see *Audio*).

| Path | What it is |
|---|---|
| `media/courses/*.webp` | Course thumbnails. One gradient field plus one geometric motif per course, from a shared six-colour palette. |
| `media/avatars/a01–a24.webp` | Learner avatars. Abstract head-and-shoulders shapes, no facial features. |
| `media/org/logo.webp` | Organisation mark. A shape, not a wordmark. |
| `media/org/thumbnail.webp` | Organisation banner. |
| `media/podcasts/*.webp` | Three square podcast covers, drawn by the same Pillow code path (`build_podcast_cover`). |

## Audio

`media/podcasts/*.mp3` holds ten spoken episode intros. The scripts are ours;
the voice is not. `build_episode_audio` renders each clip with macOS `say -v
Daniel`, then `ffmpeg -b:a 24k -ac 1` (`apps/api/scripts/build_demo_media.py:216-225,229-247`).
The rendered files are committed, so the generator only runs on a Mac
when a script changes — and where `say` or `ffmpeg` is missing it prints a skip
line and leaves the existing file in place rather than failing.

Two consequences this document has to state rather than imply: the redistribution
position for those clips rests on the macOS voice-output terms, not on Pillow
authorship, so they are the one asset class here that is not covered by the
"original work" claim above; and a non-Mac re-run silently produces nothing, so
"re-running reproduces the bytes" is true of the images only. If that voice
licence cannot be confirmed for redistributed copies, replace the clips with
audio from a licensed or openly licensed text-to-speech voice before shipping
the bundle anywhere off this repository.

Deliberately **not** used:

- **Photographs of people.** Forty fictional learners with real faces would
  need model releases, and using real photographs for invented people is
  misleading regardless of the licence.
- **AI-generated faces.** Unsettling at small sizes, and the licensing position
  is unsettled.
- **Stock imagery.** Even permissively licensed stock drifts out of visual
  consistency the moment someone adds one more image from a different source.

## Written content

The six courses, their assignments and all persona names are written for this
bundle. The organisation, "Riverbend Supply Co.", and its academy are invented.

The content is deliberately generic (onboarding, writing, support, product
knowledge, working with numbers, and compliance) so that it reads as plausible
to a prospect in any industry without resembling any particular customer's
material.

**No real customer, client or partner may be referenced anywhere in this
bundle**, including in course text, organisation details, persona names,
assignment scenarios or image filenames. `test_demo_bundle.py` enforces this
with a denylist check; extend the denylist rather than relying on review.
